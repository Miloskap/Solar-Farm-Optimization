Solar Farm Location Optimization
Geospatial analysis of ~1,500 U.S. utility-scale solar farms using NREL GHI raster data. Models two relocation scenarios — a theoretical optimum and a realistic 250-mile constrained optimization — finding that better site selection could increase total solar generation potential by ~5.6% without disrupting regional grid infrastructure.
Tools: Python, GeoPandas, Rasterio, NumPy, Matplotlib
Data Sources: NREL NSRDB GHI Raster, U.S. Photovoltaic Database (USPVDB v3.0), Natural Earth Boundaries
